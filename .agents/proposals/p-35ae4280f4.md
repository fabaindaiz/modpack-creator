A host's list of commands exempted from its shell sandbox matches the whole command as written: the same command with an argument, a redirection or a pipe is not exempted and runs inside the sandbox, where it may fail in ways that look unrelated (a socket or a temporary directory refused). Exempt the command with its arguments, or run it exactly as listed and read its output whole.

## Evidence

Container and gate scripts were exempted by their bare names; run with an output directory argument or with their output redirected to a file, they failed inside the sandbox creating a temporary directory, and only succeeded run bare. Switching branches also failed while the sandbox forbids writing the assistant's own settings file, which differs between the branches; the user had to run that command outside the sandbox.
