# Proposal: steps-readable-by-a-permission-layer

A step the agent cannot run, because the sandbox or a permission rule denies it, is handed to the human as one command that pastes on one line, with no shell variable and no line break, so it does not break when copied.

## Evidence

One carrier, 2026-10-12: during a bundle update the sandbox denied copying the bundle, installing the skills, emptying the incoming folder and editing a settings file, so the human ran them; two of the commands failed when pasted, one built on a shell variable and one broken across two lines. On 2026-10-21 the same update's denied steps were handed as single pasteable lines and ran first time.
