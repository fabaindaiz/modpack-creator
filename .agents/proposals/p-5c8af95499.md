# Proposal: usage-store-unwritable-under-sandbox

The tool's usage command writes to a per-user application-data folder that a host's shell sandbox does not allow writing to, so usage data the user consented to cannot be recorded at all; the store's path needs an override inside what the sandbox allows.

## Evidence

One carrier, two closes (2026-10-12 and 2026-10-13): the close's usage step failed on the sandbox each time and nothing was stored.
