# Proposal: an-answer-to-a-misdescribed-option-is-superseded

Two more occurrences, in a second carrier, of an answer given against a wrong description of an option: in both, the correction came from the source (a walk that read the code, or the owner's own free text), not from the option menu, and the decision was put again or rewritten in the record.

## Evidence

One carrier, one owner (the candidate's first carrier belongs to the same owner). First: while deciding a design, the agent told the owner that an option's effect applied per server; a second walk in a clean context, reading the code, showed it applies to the whole pack, and a later decision written as a correction of the first replaced it. Second: an option about which unit a suggestion is made for was framed per item; the owner picked the recommended option but said in its free text, and again mid-turn, that it was meant per release, and the decisions log records that row as corrected by the owner. Both descriptions were written from the agent's reading of the conversation, not from the code.
