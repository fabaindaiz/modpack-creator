# Proposal: a-regenerated-golden-certifies-the-generator

A test that computes the value from before a change with the changed code copies the defect it was meant to catch: the expected value has to be written by hand, or read from a record stored before the change.

## Evidence

2026-10-13, one carrier: two tests meant to prove that a request's digest was unchanged for records stored before two new fields built the old digest by dumping the new model, empty new fields included, so they passed exactly while the new fields changed every stored digest. An isolated review found it; the tests now remove the new fields by hand before hashing. A new form of the candidate's case: the expected value regenerated by the code under test. Literature: the candidate's own; no new source consulted.
