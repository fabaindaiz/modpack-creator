# Proposal: a-decline-is-revisited-when-reoffered

An entry of the carrier's declined list is put before the owner again when a newer release brings the same proposal, or when the reason it was declined no longer holds; the update procedure today reconsiders it only when the release changes the reason.

## Evidence

One carrier: the owner made it a rule on 2026-10-12; it was applied once, when a counted friction (a prose rule broken in every session of a period) undid the reason a hook had been declined, and the hook went back to the owner as a pending decision.
