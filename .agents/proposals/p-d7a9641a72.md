# Proposal: reproduce-the-checkout-not-only-the-environment

The ignore file of an image build is one more checkout: it can leave out a file the build then copies, and a gate that runs in the full working tree stays green. A test that reads the ignore file and checks every path the build copies, or a CI job that builds the image, closes it.

## Evidence

2026-10-13, one carrier: a build-context ignore rule excluded a scripts folder, and the image build needed one script from it; the gate passed in the working tree, an isolated final review found it, and a test that parses the ignore file against the build's copy steps now fails on it.
