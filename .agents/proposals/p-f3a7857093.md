# Proposal: reproduce-the-checkout-not-only-the-environment

A suite run in the working tree reads each file when it is first loaded, not when the run starts, so editing the tree while the suite runs produces failures of a state that never existed. A run whose answer is to be believed runs from an export of the commit, or the tree is left untouched until it ends.

## Evidence

One carrier, one owner, one occurrence. While the real-store suite ran (a few minutes), routes and services were edited to see a red with the implementation set aside; templates are read on demand, so about twenty import and diagnostics tests failed on the half-applied change, not on the code. The next run, with nothing touched, was green. The session log records the rule not to touch templates or routes while that suite runs.
